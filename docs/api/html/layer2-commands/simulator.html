cocos simulator

Build and launch the Cocos simulator preview

源码：src/commands/simulator.ts

选项

标志是否必填说明
-j, --project <path>可选Path to the Cocos project
-p, --port <number>可选Port number for the preview server
-s, --scene <sceneUrlOrUuid>可选Start scene (uuid or db:// url); defaults to project start scene
-e, --engine-path <path>可选Path to the Cocos engine (defaults to the bundled engine)
--build可选Build the native executable and runtime artifacts before launching
--resolution <WxH>可选Simulator window resolution, e.g. 960x640
--landscape可选Start in landscape orientation
--show-console可选Show the simulator console window
