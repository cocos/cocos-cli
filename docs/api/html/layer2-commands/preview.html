cocos preview

Preview a Cocos project

源码：src/commands/preview.ts

选项

标志是否必填说明
-j, --project <path>可选Path to the Cocos project
-p, --port <number>可选Port number for the preview server
-P, --platform <platform>可选Target web platform (web-desktop or web-mobile)
-c, --build-config <path>可选Specify build config file path
-s, --scene <sceneUrlOrUuid>可选Start scene (uuid or db:// url); defaults to project start scene
--no-open可选Do not open the preview URL in browser
--build可选Use the legacy build-based preview (full build then serve) instead of the dynamic serve preview
--scene-editor可选Start the scene editor debug preview instead of the game preview
