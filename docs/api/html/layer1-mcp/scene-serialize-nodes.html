description（会注入 LLM）：Serialize nodes and their subtrees from the currently opened source scene as one transferable batch. Removes duplicate selections and descendants already covered by a selected parent, preserving references within the batch. Does not modify the scene, clipboard, or undo history. Keep the complete returned data unchanged, then open the destination scene in the same project and pass it to scene-create-nodes-by-serialized-data. The source scene may be closed after serialization.
