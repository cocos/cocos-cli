scene-regenerate-polygon-2d-points

Component method regeneratePolygon2DPoints

Regenerate cc.PolygonCollider2D points from the alpha contour of a Sprite on the same node. Falls back to the UITransform rectangle when no usable Sprite source exists. This overwrites the current points and records undo by default.
