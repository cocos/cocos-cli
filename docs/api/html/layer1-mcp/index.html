第 1 层 — 工具（MCP）

模型侧工具定义通常是 name + description + inputSchema（经 hook 改写后的 jsonSchema7）。

tools/list 另可带 title（UI）与 outputSchema（结果校验），宿主不一定塞进提示词。见 src/mcp/mcp.middleware.ts。
