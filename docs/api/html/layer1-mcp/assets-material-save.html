assets-material-save

Assets 方法 saveMaterial

给 LLM 的提示词只靠以下内容

Agent / PinK 调用 MCP 时，模型不会看到本 HTML 文档站、源码注释或中文附录。 运行时经 tools/list（见 src/mcp/mcp.middleware.ts）注入的字段只有：

  • name — 来自 @tool('...')
  • title — 来自 @title('...')
  • description — 来自 @description('...')
  • inputSchema — 注册后的 Zod → zodToJsonSchema({ target: 'jsonSchema7', $refStrategy: 'none' })（含 hook 改写）
  • outputSchema — 来自 @result(ZodSchema)

部分工具在注册时会改写参数 schema（例如 BuilderHook 把 builder-build.options 收成空 object passthrough）。 本页展示的是改写后、与 tools/list 一致的契约，不是源码里未改写的完整 Zod 联合。

因此：想改 Agent 行为，请改装饰器 / hook / Zod describe；本页其余说明仅供人类阅读，不会进入 LLM 上下文。
