assets-animation-mask-import-skeleton

Assets method importAnimationMaskSkeleton

Import joint paths from a Prefab or glTF-scene asset into an AnimationMask. Existing joint states are preserved and missing paths are appended as enabled. Pass the glTF-scene sub-asset UUID when possible.
